# 文章提取 Markdown

Windows 10 桌面应用：输入 CSDN、微信、知乎或博客园文章链接，自动把文章正文和图片提取到本地 Markdown 文件。

## 功能

- 界面选择文章来源：CSDN、微信、知乎或博客园
- 界面输入文章链接（支持粘贴，粘贴时根据域名自动切换文章来源）
- 界面选择 Markdown 保存路径或目录
- 自动下载文章图片，保存到 Markdown 同目录下的 `<markdown文件名>_assets` 文件夹（例如 `test.md` 对应 `test_assets`），并在 Markdown 中使用相对路径引用
- 自动去掉正文中无文字的装饰性空标题（如微信排版中的空 H1），不生成孤立的 `#` 行
- 正文中带可见文本的 SVG 图示/时间轴会尽量保留，包括 `svg` 标签本身和 SVG 图片；纯装饰 SVG 仍会过滤
- 支持续写：把新文章追加到已有 Markdown 文件末尾；已有非空 Markdown 严格禁止覆盖，选择覆盖模式时会取消写入
- 覆盖（替换）模式只允许写入新文件或空文件；若目标 Markdown 已有内容，程序会报错停止，原文件内容不会被改写
- 续写时图片编号会接着已有 markdown 中的图片引用和 assets 目录文件继续累加，不会从 0 重新开始，也不会覆盖已有图片
- 输出格式：标题、来源链接、作者、CSDN 发布时间、提取时间、正文
- 提取时间写在引用块中，格式为 `update 年/月/日 xx : xx`
- 文章头部引用块（`> 来源：` / `> update ...`）与正文之间自动保留空行，正文不会被渲染进引用块
- 可选「保存长截图」：勾选后把当前文章渲染成整页长图 PNG，保存到该 Markdown 同名的
  `<文件名>_assets` 图片目录下，图片文件名用文章标题（如 `articles_assets\什么是上电复位POR.png`）；
  默认调用本机 Chrome 或 Edge 的无头模式，无需额外依赖；也可勾选「用 FSCapture 自动长截图」改成自动打开可视浏览器并触发 FastStone Capture 的滚动截图；
  选中后会自动按“保存长截图”处理（无需再单独勾选保存长截图），需要本机已安装 FSCapture，且它已配置为自动保存到文件或复制到剪贴板；
  用于公众号链接失效后仍能查看原文样式。失败不影响 Markdown 提取，会在日志中提示。
  （微信正文常带初始隐藏样式，已做强制显示处理，不会截出空白长图。）
  长截图按原页面排版一并截取顶部：公众号名/作者行（文章标题前的内容）→ 标题 → 原创/作者/发布时间 → 正文。
  勾选「保存长截图」时，在文章头部引用块内、`update` 行后加一行加粗「已截图」标记。
- 自动目录：写入新文件或空文件时在文件顶部自动生成「目录」，列出文章与 1~3 级小节
  （`<!-- toc-start -->` / `<!-- toc-end -->` 标记包裹），目录项不带 `-`，用缩进保留层级，点击可跳转到对应标题。
  续写/覆盖写入时会按当前文档结构重新编号标题并重建目录，手动改动过的标题层级会在下一次写入时自动补齐；
  旧目录格式与现在不一致时以当前格式为准（文件里始终只有一份目录）。
- 可选「重排标题/目录」：对当前 Markdown 文件仅执行标题重编号和目录重建，不追加新文章；
  操作前会自动生成一份同目录 `.bak-时间戳` 备份。
- 链接备份：每次成功写入文章后，把一行「序号 | 日期时间 | 文章链接 | Markdown 文件路径」追加到当前
  Markdown 同级目录下的 `backup.md`（目录不存在会自动创建），序号在已有条目基础上持续累加，
  日期时间格式 `YYYY/MM/DD HH:MM:SS`；链接与写入的 Markdown 文件一一对应，
  如果写入时没有显式传入 URL，则会回退读取 Markdown 里的首个 `> 来源：` 行；
  备份失败不影响文章提取，会在日志中提示。
- 同链接覆盖更新：续写时若新文章链接（`> 来源：`）在本文件已存在，不追加重复文章，
  而是用最新提取内容原地替换原文章，保持原文章编号与位置，其余文章不动，顶部目录照常重建。
- 一键去重：Markdown 路径行新增「去重」按钮，把同一链接的重复文章清理成一篇
  （每个链接只保留 `update` 时间最新的一篇，其他删除），全部文章重新编号 1..N 并重建目录；
  操作前自动在文件旁生成 `文件名.bak-时间戳` 备份，弹窗确认后才执行。
- 可选「输出 PDF」：勾选后把整份 Markdown（含此前追加的所有文章）输出为 PDF，保存到 Markdown 同目录的 `PDF` 文件夹，
  文件名与 Markdown 同名（如 `debug.md` 生成 `PDF\debug.pdf`）；
  内置轻量 Markdown→HTML 转换器渲染全文（标题/引用/列表/表格/代码块/图片均支持，标题带锚点 id），
  调用本机 Chrome/Edge 无头模式自动分页，并用内置 pypdf 把文章标题层级写入 PDF 书签（左侧标签栏可跳转），
  目录页链接在 PDF 内可点击；引用块以绿色显示；失败不影响 Markdown 提取，会在日志中提示。
- 标题自动编号：每次提取的文章一级标题按 `1、2、3...` 编号，文章内小节按 `1.1、1.1.1...`；
  即使文章正文里自带 `#` 一级标题，也会并入当前文章编号，不会被拆成多篇文章；
  正文第一个标题若与文章标题完全相同（微信文章常在正文开头重复标题），会自动跳过，避免标题重复出现；
  微信正文里以「一、」「二、」等中文序号开头、且不带句末标点的短行会被识别为小节标题并自动编号
  （如 `3.2 寄存器属性测试`）；
  微信列表项里误带的标题标记（`- ### 标题`）会自动去掉，按普通列表项/段落处理；
  微信正文里 `- 小标题` 列表项后的内容会自动缩进到列表项下，与 `-` 保持同一层次（含嵌套列表；
  标题/内容被 `<section>` 等标签包裹时同样识别）。
  微信正文偶发的 2 空格缩进列表项（`  - 小标题`，其后内容只缩进 2 空格）会自动降为顶格 `- 小标题`，
  内容与 `-` 保持同一层次；

## 运行

需要 Python 3.10 或更高版本：

```bat
cd D:\sandbox\extract_csdn_wechat_article
python -m pip install -r requirements.txt
python main.py
```

## 打包为 exe

双击 `build.bat`，或手动执行：

```bat
python -m PyInstaller --noconfirm --clean --windowed --onefile ^
  --name Article2Markdown ^
  --hidden-import markdownify ^
  --hidden-import bs4 ^
  --hidden-import lxml ^
  main.py
```

生成文件：`dist\Article2Markdown.exe`。

## 使用说明

1. 在「文章来源」选择 CSDN、微信、知乎或博客园。
2. 需要时在「Cookie（可选）」粘贴浏览器里的 CSDN Cookie（见下文）。
3. 在「文章链接」输入框粘贴文章地址。
4. 在「Markdown 路径」选择已有 `.md` 文件或保存目录；不填则保存到当前目录。
5. 选择写入方式：
   - 续写（追加）：新文章追加到已有 Markdown 后面，中间用 `---` 分隔。
   - 覆盖（替换）：只用于新文件或空文件；如果目标 Markdown 不是空文件，程序会拒绝写入，严格不覆盖原内容。
6. 点击「开始提取」，等待完成。

## CSDN 安全验证 / 正文不全

普通 CSDN 文章只需要链接即可提取。知乎文章匿名访问通常会返回 403
“请进行安全验证”类拦截，少部分 CSDN 页面也会返回安全验证页，
或者正文被折叠、只显示一部分，这时可以：

1. 用浏览器登录 CSDN 并打开文章。
2. 按 F12 打开开发者工具，切到 Network 面板。
3. 刷新页面，点第一个请求，复制 Request Headers 里的 `Cookie` 值。
4. 粘贴到 app 的「Cookie（可选）」输入框后再提取。

「阅读全文」这类遮罩多数只是 CSS 折叠，完整正文本来就在页面 HTML 里，
程序会自动去掉遮罩；Cookie 主要用来绕过安全验证和需要登录态的页面。
付费或私密内容仍需要对应账号权限。

注意：移动 Markdown 文件时，要连同旁边的 `<markdown文件名>_assets` 目录一起移动，图片才能正常显示。

## 项目结构

  main.py                 # 程序入口

  wechat_extractor.py     # 微信文章提取
  csdn_extractor.py       # CSDN 文章提取
  zhihu_extractor.py      # 知乎文章提取
  cnblogs_extractor.py    # 博客园文章提取
  test_extractor.py       # 微信核心逻辑测试
  test_csdn_extractor.py  # CSDN 核心逻辑测试
  test_zhihu_extractor.py # 知乎核心逻辑测试
  test_cnblogs_extractor.py # 博客园核心逻辑测试
  test_screenshot.py      # 长截图模块测试（浏览器可用时含端到端截图测试）
  requirements.txt        # 依赖
  build.bat               # Windows 打包脚本
